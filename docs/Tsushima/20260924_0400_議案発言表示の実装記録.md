# 対馬市版・議案に関する発言表示の実装記録

## 今回追加したもの

- 議案詳細に、発言者名・発言時の肩書き・党派・会派・日付・会議名を表示。
- 討論・質疑・答弁・説明を区別。討論の意見と採決結果を混同しない説明を表示。
- 要約と発言原文を分け、出典URL・ページ番号などを表示。
- 管理画面の議案編集から追加・編集・公開解除。公開前には内容・出典の確認が必須。内容の編集で確認チェックを解除。
- 議案と発言が両方公開済みの場合のみ公開側で取得。RLS有効、一般利用者用ポリシーなし。保存は管理者認証後のサーバー処理だけで行う。
- 未掲載と取得失敗を区別し、未掲載を「発言なし」と断定しない。

党派はサイト運営政党の設定とは独立しています。自民・立憲・公明なども、発言時の正式な所属を確認して登録すれば表示できます。所属が不明なら空欄にします。

参考にした画面: [福津市版・議案詳細](https://mirai-gikai-fukutsu.jp/bills/a11d2beb-8a65-442a-8fab-e60c28669927)。表示する氏名・発言は対馬市の公式会議録で別途確認します。
