## 3. シードデータ案

対象は `packages/seed/main/data.ts`。手順書の概念例とは異なり、現行実装は `councilSessions`・`factions`・`committees` の名前でexportし、会派は `name`（内部キー）と `display_name`（表示名）を使う。以下は現行DBのInsert型に合わせた設計例であり、まだDBには投入しない。

### 3.1 定例会

公式の[会期日程（案）](https://www.city.tsushima.nagasaki.jp/material/files/group/2/R8-3T-kaiki.pdf)は、令和8年第3回定例会を2026年9月8日から9月25日までとしている。**日程は案**のため、本番投入前に確定内容を確認する。`slug` は内部識別子の提案、`is_active` は公開対象を決める運用設定であり、開催中かどうかだけで確定しない。

```typescript
import type { Database } from "@mirai-gikai/supabase";

type CouncilSessionInsert =
  Database["public"]["Tables"]["council_sessions"]["Insert"];
type FactionInsert = Database["public"]["Tables"]["factions"]["Insert"];
type CommitteeInsert = Database["public"]["Tables"]["committees"]["Insert"];

export const councilSessions: CouncilSessionInsert[] = [
  {
    name: "令和8年 第3回対馬市議会定例会",
    slug: "r8-3",
    council_url:
      "https://www.city.tsushima.nagasaki.jp/gyousei/soshiki/gikaijimukyoku/gikai/oshirase/6880.html",
    start_date: "2026-09-08", // 会期日程（案）。確定日程は要確認
    end_date: "2026-09-25", // 同上
    is_active: false, // 対象会期の確定後、表示方針に従って変更
  },
];
```

### 3.2 会派

[会派別議員名簿](https://www.city.tsushima.nagasaki.jp/gyousei/soshiki/gikaijimukyoku/gikai/450.html)（令和7年6月10日調製）に基づく。`name` の英字表記・並び順は本システム内の提案で、公式表記ではない。`is_active: true` は名簿掲載会派を利用する案であり、現況確認を投入条件とする。

```typescript
export const factions: FactionInsert[] = [

  { name: "mirai-kaikaku", display_name: "未来改革", sort_order: 2, is_active: true },

```

議員名簿の「党派」と会派は別概念。「公明」を推測で「公明党議員団」等へ変えない。会派に掲載されない議員の所属も推測で補完せず要確認とする。

### 3.3 委員会

[委員会名簿](https://www.city.tsushima.nagasaki.jp/gyousei/soshiki/gikaijimukyoku/gikai/iinkai/525.html)を参照。総務文教厚生・産業建設・議会運営は令和8年6月1日、議会広報編集・国境離島活性化推進は同年8月17日、議会改革は同年6月19日調製。所管の詳細は未確認のため `description: null` とする。公開前に存続・名称を再確認する。

```typescript
export const committees: CommitteeInsert[] = [
  { name: "総務文教厚生委員会", description: null, sort_order: 1, is_active: true },
  { name: "産業建設委員会", description: null, sort_order: 2, is_active: true },
  { name: "議会運営委員会", description: null, sort_order: 3, is_active: true },
  { name: "議会広報編集特別委員会", description: null, sort_order: 4, is_active: true },
  { name: "国境離島活性化推進特別委員会", description: null, sort_order: 5, is_active: true },
```

他団体の議会議員（病院企業団・広域連合等）は委員会ではないため、この配列には含めない。

### 3.4 投入前の確認

- 上記3配列だけを置換して既存の `pnpm seed` を本番実行しない。サンプル議案、説明文、会派賛否、委員会・会期との関連付けも一体で差し替える。
- シードはまずローカルの検証用DBで確認する。架空のテスト議案と公式情報を区別し、本番公開対象にテストデータを含めない。
- [議案及び審議結果](https://www.city.tsushima.nagasaki.jp/gyousei/soshiki/gikaijimukyoku/gikai/gian-shingikekka/index.html)には、議員ごとの賛否一覧は賛否が分かれた場合のみ掲載する旨がある。一覧がないことだけで全会派賛成・全会一致を推定しない。
- 過去会期の賛否は、その採決時点の会派・議員所属と照合する。現在の名簿を遡及適用しない。

| 追加・補足項目 | 用途 | 必須/任意・設定案 |

`.env.example` を `.env` にコピーし、対馬市版用の値を設定する。サンプルのローカルSupabaseキーや旧地域の接続先を本番へ転用しない。サービスロールキーや各API秘密鍵はサーバー側のみで扱い、`NEXT_PUBLIC_` を付けない。`REVALIDATE_SECRET` はwebとadminで一致させる。
